### 2026-10-06 변경 · 안건 2 를 Gemini 로

사용자가 받아쓰기와 세 항목 구분에 **Gemini API** 를 쓰기로 정했다. 처음에는 OpenAI 로 정했었다.

- 받아쓰기: 오디오를 Gemini 에 넣어 한국어 전문을 받는다. 15MB 이하는 요청에 바로 싣고, 넘으면 Files API 로 먼저 올린다 (요청 전체 20MB 제한)
- 세 항목 구분: 같은 모델에 JSON 출력(`response_mime_type=application/json`)으로 부른다
- 모델은 `.env` 의 `STT_MODEL` · `LLM_MODEL`, 기본값 `gemini-3.1-flash-lite`. 키 이름은 프로그램정의서대로 `STT_API_KEY`
- SDK 는 `google-genai`. `openai` 는 의존성에서 뺐다

### 함께 정한 기본값

- 사용자당 팀은 하나. 퍼블리싱에 팀 전환이 없다. `GET /api/teams` 는 0~1건
- 화면이 쓰는 API 는 스토리보드 I-01 통합매핑표를 따른다. 로그인 화면 장마다 적힌 5개가 아니라 매핑표의 3개
- 문서에 없는 HTTP 상태는 퍼블리싱에 적힌 값을 따른다. `TEAM_FULL` 409 · `UNSUPPORTED_MEDIA_TYPE` 415 · `PAYLOAD_TOO_LARGE` 413
- 개발이 끝나면 pytest 를 짜서 돌리고 결과를 보고한다
- `tasks.md` 맨 아래에 사람이 눈으로 확인하는 수락 항목 하나를 둔다 (화면 6종 · 360px 포함)
